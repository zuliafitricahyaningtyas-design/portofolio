Panduan Upload ke GitHub

Langkah resmi sesuai Buku Panduan Tutorial Portofolio

1. Cek Git Terpasang

Buka terminal VS Code / CMD, ketik:

git --version

2. Buat Repositori di GitHub

Login ke GitHub → Klik New Repository → Beri nama (misal: portfolio) → Pilih Public → Klik Create Repository.

3. Eksekusi Perintah Git

Jalankan perintah ini secara berurutan di terminal folder project:

git init
git add .
git commit -m "First commit portofolio Zulia"
git branch -M main
git remote add origin https://github.com/USERNAME/NAMA-REPOSITORY.git
git push -u origin main

Cara Publish Website (GitHub Pages)

Di GitHub, masuk ke Settings → Pages → Pada bagian Branch pilih main → Klik Save. Tunggu 1-2 menit, website Anda akan online!
